# Jeson联机渲染发送口

按你最新要求实现：

- 缓存目录：`\\wj114\01 完全共享\联机渲染\渲染缓存`
- 临时渲染输出：`\\wj114\01 完全共享\联机渲染\渲染输出`
- 若发送时填写“指定输出路径”，渲染完成后会复制一份到指定路径
- 面板按钮：`发送渲染队列` / `发送当前文件` / `查看任务列表`
- 任务列表网页：`http://192.168.30.212:8000/dashboard`
- 渲染主机固定：`WK1021` `WK1042` `WK1043` `WJ410`
- 新增：渲染机托盘小软件（可开机自启、右下角图标显示运行状态、可停止/退出）

## 使用步骤

### 1) 启动服务器（192.168.30.212）

```bash
pip install -r requirements.txt
uvicorn server.app:app --host 0.0.0.0 --port 8000
```

### 2) 方案A：命令行启动四台渲染机

```bash
python agent/worker.py --server http://192.168.30.212:8000 --host WK1021
python agent/worker.py --server http://192.168.30.212:8000 --host WK1042
python agent/worker.py --server http://192.168.30.212:8000 --host WK1043
python agent/worker.py --server http://192.168.30.212:8000 --host WJ410
```

### 3) 方案B：托盘小软件（推荐）

在每台渲染机运行：

```bash
python agent/tray_worker.py
```

> 托盘程序已内置 worker 轮询逻辑，不依赖外部 `worker.py` 文件路径；只要这台机器能运行 `tray_worker.py` 就可以。

功能：
- 启动后自动最小化到系统托盘（右下角图标）
- 绿点=运行中，红点=已停止
- 托盘菜单可：启动渲染节点、停止渲染节点、开机自启、打开配置文件、退出
- 配置文件路径：`%USERPROFILE%/.jeson_worker_config.json`

> 第一次运行建议先在托盘菜单点“打开配置文件”，把 `host` 改为对应主机名（WK1021/WK1042/WK1043/WJ410），保存后重启托盘程序。

### 4) Blender 发送任务

安装插件后，在“输出 > 联机发送”里：
- `发送渲染队列`：把 `scene.render_queue` 中任务拷贝到缓存目录后提交。
- `发送当前文件`：把当前 `.blend` 拷贝到缓存目录，命名为 `文件名_五位随机数.blend` 后提交。
- `查看任务列表`：直接打开网页看板。

### 5) 输出规则

- 渲染始终先输出到临时渲染输出目录：`\\wj114\01 完全共享\联机渲染\渲染输出`
- 如果发送时填了“指定输出路径”，worker 会把渲染结果复制一份到该路径。
