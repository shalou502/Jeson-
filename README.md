# Jeson联机渲染发送口（便携双击版）

你可以把整套目录当“便携版”使用，双击 `.cmd` 文件启动。

脚本会自动尝试 `python` 或 `py -3`。若缺少 Python 会自动打开官方下载页。

## 双击启动入口（Windows）

- `启动渲染节点托盘.cmd`：渲染主机双击启动（右下角托盘）
- `启动管理端服务.cmd`：管理端/服务器双击启动 FastAPI 服务，并自动打开任务看板网页
- `打开任务看板.cmd`：双击直接打开网页看板

## 如果双击报“不是内部或外部命令”

常见原因：
1. 没安装 Python，或 Python/py 启动器没加到 PATH
2. 你运行目录里缺少 `agent/`、`server/` 这些文件夹

先在命令行检查（两个都试）：

```bat
python --version
py -3 --version
```

若没有版本号，请安装 Python 并勾选“Add python.exe to PATH”。

## 日常使用（新手推荐）

### 1) 管理端机器

双击：`启动管理端服务.cmd`

- 会先检查文件路径和 Python
- 会自动安装/校验依赖
- 会自动打开网页看板
- 若启动失败，会直接在窗口显示详细报错

### 2) 每台渲染机

双击：`启动渲染节点托盘.cmd`

托盘功能：
- 自动最小化到右下角
- 绿点=运行中，红点=停止
- 右键菜单：启动/停止、开机自启、打开配置、退出

配置文件路径：`%USERPROFILE%/.jeson_worker_config.json`

> 第一次运行建议先在托盘菜单点“打开配置文件”，把 `host` 改为对应主机名（WK1021/WK1042/WK1043/WJ410），保存后重启托盘程序。

### 3) 查看状态

双击：`打开任务看板.cmd`

## Blender 插件安装（只放插件目录）

`Jeson联机渲染/__init__.py` 必须在插件目录根。

```text
Jeson联机渲染/
  __init__.py
```

不要把整个项目根目录（含 `agent/`、`server/`）当 Blender 插件目录。

---

## Blender 发送任务

在“输出 > 联机发送”里：
- `发送渲染队列`：把 `scene.render_queue` 中任务拷贝到缓存目录后提交。
- `发送当前文件`：把当前 `.blend` 拷贝到缓存目录，命名为 `文件名_五位随机数.blend` 后提交。
- `查看任务列表`：直接打开网页看板。


## 管理端打不开网页时的排查

如果浏览器提示连接失败，通常是服务没有真正启动。
现在 `启动管理端服务.cmd` 会自动：
1. 检查项目路径（`server/app.py`、`requirements.txt`）
2. 检查 Python
3. 安装/校验依赖
4. 打开看板并启动 uvicorn

若仍失败，启动窗口会直接显示详细错误（端口占用/防火墙/依赖安装失败等）。


### 管理端常见错误

- 若提示 `server\app.py not found`：说明你不是在项目根目录双击启动。
- 若提示 `pip install failed`：检查网络或代理，再手动执行 `python -m pip install -r requirements.txt`。
- 若 uvicorn 报端口占用：改成 `--port 8001` 再试。
